The tool draws on top of the game, so badly configured visuals cost frames.
These settings keep the cost low.

| **Setting** | **Frame cost** | **Recommendation** |
| --- | --- | --- |
| **ESP boxes** | Low | Keep on |
| **Skeletons** | Medium | Off in busy fights |
| **Distance numbers** | Low | On |
| **Loot highlights** | Medium | On only when looting |
| **Radar** | Low | Keep on |
| **Full-screen ESP** | High | Avoid |

**Practical rules**

1. Turn off anything you are not actively looking at.
2. Keep the ESP distance limit around 200–300 m; rendering the whole map is
   wasted work.
3. If your frame rate drops in a crowded area, disable skeletons first.
4. Close the overlay when you do not need it — a hidden menu costs nothing.

**Hardware notes**

- 8 GB RAM is enough; the tool itself uses a few hundred MB.
- The overlay runs on the GPU, so a weak card benefits most from the settings
  above.
- Fullscreen exclusive can block drawing on some drivers — use borderless.

## 🚫 Common Mistakes

Most problems people report come from one of these.

| **Mistake** | **Why it hurts** | **Do this instead** |
| --- | --- | --- |
| Running before the game | Overlay cannot attach | Start the game first, then the loader |
| No administrator rights | Cannot read game memory | Right-click → run as administrator |
| Rage settings in public | Obvious to everyone | Use the legit preset |
| Old build after a patch | Will not attach | Download the current build |
| Antivirus exclusion skipped | File quarantined silently | Add the folder first |
| Two overlays at once | Drawing conflicts | Close Discord / Afterburner overlays |

**The one that catches most people**

Windows Defender scans a new executable the first time it runs. If the file
disappears right after download, it was quarantined — not deleted by the app.
Restore it and add the folder to exclusions before launching again.

**The one that gets people noticed**

Aimbot with high FOV and low smoothing is the single most visible setting in
the tool. If you only change one thing, lower the FOV.
